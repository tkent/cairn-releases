# cairn releases

Release binaries for **cairn**: knowledge in
[Open Knowledge Format (OKF)](https://github.com/GoogleCloudPlatform/open-knowledge-format),
as a CLI and an MCP server in one static binary.

## Install

macOS and Linux:

```sh
brew install tkent/tap/cairn
```

Windows: download `cairn_<version>_windows_<arch>.zip` from
[Releases](https://github.com/tkent/cairn-releases/releases) and put `cairn.exe` on your `PATH`.

Each release includes `checksums.txt` (`sha256sum -c` format).

This repository holds only release artifacts.
